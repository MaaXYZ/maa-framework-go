# v4.0.0

[中文](#中文) | [English](#english)

## 中文

### 破坏性变更

- 最低 Go 版本提升至 1.25，模块路径由 `/v3` 升为 `/v4`。 [@dongwlin](https://github.com/dongwlin)
- 构造函数和多数配置、查询、运行接口改用 Go `error` 返回失败原因。 [@dongwlin](https://github.com/dongwlin)
- 所有 `Post*` 方法改为返回 Job 与提交错误；异步执行结果仍需通过 `Wait().Success()` 检查。 [@dongwlin](https://github.com/dongwlin)
- `Destroy` 改为返回错误，拒绝销毁借用对象，以及仍被绑定、使用或处于回调中的对象。 [@dongwlin](https://github.com/dongwlin)
- 回调收到的 `Context` 及其 `Clone` 在该次回调返回后失效。 [@dongwlin](https://github.com/dongwlin)
- Pipeline 构造 API 移除大量 `Node` 类型前缀和配置 option，改用参数结构与节点链式设置。 [@dongwlin](https://github.com/dongwlin)
- `Node.UnmarshalJSON` 改为替换整个节点，重置输入中未出现的字段及 `Name`。 [@dongwlin](https://github.com/dongwlin)
- 移除 `Resource.UseCoreml`。MaaDeps 不再分发 CoreML 提供程序，原调用可迁移到 `Resource.UseWebgpu`。 [@dongwlin](https://github.com/dongwlin)
- 未 detach 的 Agent Server 在 `AgentServerShutDown` 后永久关闭，不能通过 `Release` / `Init` 重启。 [@dongwlin](https://github.com/dongwlin)
- AgentClient 统一使用 `NewAgentClient` 选项构造，原位置标识符和 TCP 构造入口分别改用 `WithIdentifier`、`WithTcpPort`。 [@dongwlin](https://github.com/dongwlin)
- `InitConfig` 不再导出；`Init` 只应用显式传入的全局配置选项，重复初始化和未初始化时的 `Release` 返回 nil。 [@dongwlin](https://github.com/dongwlin)
- 移除旧截图 setter，统一使用 `SetScreenshot(WithScreenshot*...)` 配置截图。 [@dongwlin](https://github.com/dongwlin)
- `CustomController` 必须新增实现 `RelativeMove` 和 `Shell`。 [@MistEO](https://github.com/MistEO), [@dongwlin](https://github.com/dongwlin) ([#38](https://github.com/MaaXYZ/maa-framework-go/pull/38))
- `CustomController` 必须新增实现 `Inactive` 和 `GetInfo`。 [@dongwlin](https://github.com/dongwlin)
- 移除 `CarouselImageController` 与 `NewCarouselImageController`。 [@MistEO](https://github.com/MistEO), [@dongwlin](https://github.com/dongwlin) ([#38](https://github.com/MaaXYZ/maa-framework-go/pull/38))
- 图像读取的具体返回类型由 `*image.NRGBA` 改为 `*image.RGBA`。 [@dongwlin](https://github.com/dongwlin)
- 动作和画面稳定等待的时间字段改用 `time.Duration` 或其切片；长按及长按键的 `Duration` 改为 `*time.Duration`，JSON 仍使用整数毫秒。 [@dongwlin](https://github.com/dongwlin)
- 模板、OCR 期望文本和神经网络标签列表改用 `StringList`。 [@dongwlin](https://github.com/dongwlin)
- 神经网络 `Expected` 改用 `ClassSelectors`。 [@kqcoxn](https://github.com/kqcoxn) ([#54](https://github.com/MaaXYZ/maa-framework-go/pull/54))
- `Node.Anchor` 改用 `map[string]string`；非 nil 空 map 输出 `{}`，清除节点配置但不清除已建立的运行时锚点。 [@dongwlin](https://github.com/dongwlin)
- `Context.OverrideNext` / `Resource.OverrideNext` 改收 `[]NextItem`，通过结构字段表示跳回与锚点属性。 [@dongwlin](https://github.com/dongwlin)
- And / Or 子识别改用 `SubRecognitionItem`，通过 `Ref`、`Inline` 表达节点引用与内联识别。 [@dongwlin](https://github.com/dongwlin)
- `Context.WaitFreezes` 改收固定的 `*WaitFreezesParam` 参数并返回错误。 [@dongwlin](https://github.com/dongwlin)
- `TaskDetail.NodeDetails []*NodeDetail` 改为 `TaskDetail.Nodes []NodeRef`，通过 `NodeRef.GetDetail()` 按需查询节点详情。 [@dongwlin](https://github.com/dongwlin)
- 移除 `TaskJob.Job` 字段；自定义动作与识别回调参数中的 `TaskDetail` 改为 `TaskID`。 [@dongwlin](https://github.com/dongwlin)
- 移除旧 `CustomAction` / `CustomRecognition` 别名，公开的 EventSinkAdapter 类型改为内部实现。 [@dongwlin](https://github.com/dongwlin)
- 节点查询与图像覆盖入口分别由 `Context.GetNodeData`、`Resource.OverriderImage` 改名为 `Context.GetNode`、`Resource.OverrideImage`。 [@dongwlin](https://github.com/dongwlin)
- 修正 `InterenceDevice` / `InterenceDeviceAuto` 拼写，并对齐 Win32 消息输入枚举名称。 [@dongwlin](https://github.com/dongwlin)
- `RecognitionResults.Best` 改为单个结果指针。 [@dongwlin](https://github.com/dongwlin)
- 神经网络分类结果移除 `Raw`、`Probs`。 [@MistEO](https://github.com/MistEO), [@dongwlin](https://github.com/dongwlin) ([#26](https://github.com/MaaXYZ/maa-framework-go/pull/26))
- Shell 与 next 详情的字段及 JSON 键改为 `ShellTimeout` / `shell_timeout`、`List` / `list`。 [@MistEO](https://github.com/MistEO), [@dongwlin](https://github.com/dongwlin) ([#26](https://github.com/MaaXYZ/maa-framework-go/pull/26))
- 值类型零 offset 改为省略；`Rect` 仅接受 2 或 4 个整数，`Target` 拒绝 false、null 和无效形状。 [@dongwlin](https://github.com/dongwlin)
- `CustomActionParam.CustomActionParam` 中的 JSON 数字改为 `json.Number`。 [@dongwlin](https://github.com/dongwlin)
- 识别、动作与画面稳定等待详情不可用时返回错误，取代 `(nil, nil)`。 [@dongwlin](https://github.com/dongwlin)
- Tasker 有待执行或运行中任务时，重新绑定返回 `ErrTaskerRunning`。 [@dongwlin](https://github.com/dongwlin)
- 对象仍存活或 Agent Server 未关闭时，`Release` 返回 `ErrLibraryInUse`；服务 detach 后持续禁止卸载。 [@dongwlin](https://github.com/dongwlin)

### 问题修复

- 修复多个 goroutine 等待或查询同一 Job / TaskJob 时的并发问题。 [@dongwlin](https://github.com/dongwlin)
- 修复停止使旧 Job ID 无效后，销毁可能在原生工作仍未空闲时释放对象的问题。 [@dongwlin](https://github.com/dongwlin)
- 修复 sink 与 Resource runner 注册交错的问题，串行执行注册操作。 [@dongwlin](https://github.com/dongwlin)
- 修复原生注册失败时遗留 Go 回调记录的问题。 [@dongwlin](https://github.com/dongwlin)
- 修复自定义控制器销毁期间清理回调过早释放的问题，保留 KeyUp / TouchUp 回调至原生销毁完成。 [@dongwlin](https://github.com/dongwlin)
- 修复初始化失败后部分动态库未正确清理的问题，并支持重试卸载失败的库。 [@dongwlin](https://github.com/dongwlin)
- 修复 Windows 空库目录初始化意外修改 DLL 搜索配置的问题。 [@dongwlin](https://github.com/dongwlin)
- 修复无节点任务的 Entry、Status 丢失问题。 [@dongwlin](https://github.com/dongwlin)
- 修复 Shell 输出在内嵌 NUL 处被截断的问题。 [@dongwlin](https://github.com/dongwlin)
- 修复自定义识别 detail 写入原生缓冲区时在内嵌 NUL 处被截断的问题。 [@dongwlin](https://github.com/dongwlin)
- 修复图像与矩形缓冲区创建、写入失败未传递到调用方的问题。 [@dongwlin](https://github.com/dongwlin)
- 修复 Action / Recognition 未提供 `param` 时丢失平铺参数的问题。 [@dongwlin](https://github.com/dongwlin)
- 修复 And / Or 内联识别编码缺少 `recognition` 嵌套对象的问题。 [@dongwlin](https://github.com/dongwlin)
- 修复 Swipe 动作结果解析失败时部分改写接收值的问题。 [@dongwlin](https://github.com/dongwlin)
- 参数编码失败现在报告错误并跳过原生执行，不再静默替换为 `{}`。 [@dongwlin](https://github.com/dongwlin)
- 提交失败仍返回非 nil 的终态失败 Job，保留提交错误供后续查询。 [@dongwlin](https://github.com/dongwlin)
- 修复重复或并发销毁原生对象时可能重复清理句柄的问题。 [@dongwlin](https://github.com/dongwlin)
- 串行执行 Tasker 的绑定与提交，避免任务提交和重新绑定交错。 [@dongwlin](https://github.com/dongwlin)
- AgentClient 保留绑定 Resource 和已注册 sink 对象的句柄引用，避免使用期间提前销毁。 [@dongwlin](https://github.com/dongwlin)
- 串行执行 `Init` / `Release`，并同步保护 `IsInited` 查询。 [@dongwlin](https://github.com/dongwlin)
- 修复 Unix 上 `WithLibDir(".")` 退化为系统搜索路径的问题。 [@dongwlin](https://github.com/dongwlin)
- 修复 macOS 显式库路径缺失时的加载检查，并将符号查找限定到目标库。 [@dongwlin](https://github.com/dongwlin)
- 修复 `Context.GetNodeJSON` 与 `Resource.OverrideNext` 调用了错误类别原生接口的问题。 [@dongwlin](https://github.com/dongwlin)
- 修复重复调用 Context / Tasker getter 后旧 Go 包装对象可能崩溃的问题。 [@dongwlin](https://github.com/dongwlin)

- 拒绝 nil 自定义 runner；Resource 注销不存在的名称成为成功空操作，外部注册的名称保留并返回错误。 [@dongwlin](https://github.com/dongwlin)
- 修复自定义识别返回 nil 结果时的空指针访问。 [@dongwlin](https://github.com/dongwlin)
- 自定义动作的 `reco_id` 为 0 时跳过识别详情查询。 [@zmdyy0318](https://github.com/zmdyy0318) ([#44](https://github.com/MaaXYZ/maa-framework-go/pull/44))

- 缺少识别或动作子详情时仍保留节点详情，并跳过 ID 为 0 的子详情。 [@dongwlin](https://github.com/dongwlin)
- 图像写入正确处理非零原点和带额外行间距的子图像。 [@dongwlin](https://github.com/dongwlin)

- 复制 Attach、MultiSwipe 和 ColorMatch 的相关配置数据，减少调用方后续修改对已构造配置的影响。 [@dongwlin](https://github.com/dongwlin)

## English

### Breaking Changes

- Raise the minimum Go version to 1.25 and change the module path from `/v3` to `/v4`. by [@dongwlin](https://github.com/dongwlin)
- Change constructors and most configuration, query, and execution APIs to return Go `error` values on failure. by [@dongwlin](https://github.com/dongwlin)
- Change all `Post*` methods to return a Job and a submission error; asynchronous results still require `Wait().Success()` checks. by [@dongwlin](https://github.com/dongwlin)
- Change `Destroy` to return errors and reject destruction of borrowed objects or objects still bound, in use, or in callbacks. by [@dongwlin](https://github.com/dongwlin)
- A callback's `Context` and its `Clone` now become invalid when the callback returns. by [@dongwlin](https://github.com/dongwlin)
- Remove many `Node` type prefixes and configuration options from Pipeline builders in favor of parameter structs and chained node setters. by [@dongwlin](https://github.com/dongwlin)
- Change `Node.UnmarshalJSON` to replace the entire node, resetting fields omitted from the input and `Name`. by [@dongwlin](https://github.com/dongwlin)
- Remove `Resource.UseCoreml`. MaaDeps no longer ships the CoreML provider; existing calls can migrate to `Resource.UseWebgpu`. by [@dongwlin](https://github.com/dongwlin)
- Without detach, Agent Server is permanently closed after `AgentServerShutDown`; `Release` / `Init` cannot restart it. by [@dongwlin](https://github.com/dongwlin)
- Unify AgentClient construction under `NewAgentClient` options, replacing the identifier and TCP constructor entry points with `WithIdentifier` and `WithTcpPort`. by [@dongwlin](https://github.com/dongwlin)
- Stop exporting `InitConfig`; `Init` only applies explicitly passed global options, and repeated initialization or `Release` before initialization returns nil. by [@dongwlin](https://github.com/dongwlin)
- Remove the old screenshot setters in favor of `SetScreenshot(WithScreenshot*...)`. by [@dongwlin](https://github.com/dongwlin)
- Require `CustomController` implementations to add `RelativeMove` and `Shell`. by [@MistEO](https://github.com/MistEO), [@dongwlin](https://github.com/dongwlin) ([#38](https://github.com/MaaXYZ/maa-framework-go/pull/38))
- Require `CustomController` implementations to add `Inactive` and `GetInfo`. by [@dongwlin](https://github.com/dongwlin)
- Remove `CarouselImageController` and `NewCarouselImageController`. by [@MistEO](https://github.com/MistEO), [@dongwlin](https://github.com/dongwlin) ([#38](https://github.com/MaaXYZ/maa-framework-go/pull/38))
- Change the concrete image return type from `*image.NRGBA` to `*image.RGBA`. by [@dongwlin](https://github.com/dongwlin)
- Change action and screen stabilization wait time fields to `time.Duration` or slices of it; long-press and long-press-key `Duration` fields use `*time.Duration`, while JSON still uses integer milliseconds. by [@dongwlin](https://github.com/dongwlin)
- Change template, OCR expected text, and neural network label lists to `StringList`. by [@dongwlin](https://github.com/dongwlin)
- Change neural network `Expected` to `ClassSelectors`. by [@kqcoxn](https://github.com/kqcoxn) ([#54](https://github.com/MaaXYZ/maa-framework-go/pull/54))
- Change `Node.Anchor` to `map[string]string`; a non-nil empty map emits `{}`, clearing node configuration without clearing established runtime anchors. by [@dongwlin](https://github.com/dongwlin)
- Change `Context.OverrideNext` / `Resource.OverrideNext` to accept `[]NextItem`, with struct fields for jump-back and anchor properties. by [@dongwlin](https://github.com/dongwlin)
- Change And / Or sub-recognitions to `SubRecognitionItem`, using `Ref` and `Inline` for node references and inline recognition. by [@dongwlin](https://github.com/dongwlin)
- Change `Context.WaitFreezes` to accept a fixed `*WaitFreezesParam` argument and return an error. by [@dongwlin](https://github.com/dongwlin)
- Replace `TaskDetail.NodeDetails []*NodeDetail` with `TaskDetail.Nodes []NodeRef`, querying node details on demand through `NodeRef.GetDetail()`. by [@dongwlin](https://github.com/dongwlin)
- Remove `TaskJob.Job`; replace `TaskDetail` with `TaskID` in custom action and recognition callback arguments. by [@dongwlin](https://github.com/dongwlin)
- Remove the old `CustomAction` / `CustomRecognition` aliases and make the exported EventSinkAdapter types internal. by [@dongwlin](https://github.com/dongwlin)
- Rename node query and image override entry points from `Context.GetNodeData` and `Resource.OverriderImage` to `Context.GetNode` and `Resource.OverrideImage`. by [@dongwlin](https://github.com/dongwlin)
- Correct the `InterenceDevice` / `InterenceDeviceAuto` spelling and align Win32 message input enum names. by [@dongwlin](https://github.com/dongwlin)
- Change `RecognitionResults.Best` to a single result pointer. by [@dongwlin](https://github.com/dongwlin)
- Remove `Raw` and `Probs` from neural network classification results. by [@MistEO](https://github.com/MistEO), [@dongwlin](https://github.com/dongwlin) ([#26](https://github.com/MaaXYZ/maa-framework-go/pull/26))
- Change Shell and next detail fields and JSON keys to `ShellTimeout` / `shell_timeout` and `List` / `list`. by [@MistEO](https://github.com/MistEO), [@dongwlin](https://github.com/dongwlin) ([#26](https://github.com/MaaXYZ/maa-framework-go/pull/26))
- Omit zero value-type offsets; restrict `Rect` to 2 or 4 integers, and reject false, null, and invalid shapes in `Target`. by [@dongwlin](https://github.com/dongwlin)
- Change JSON numbers in `CustomActionParam.CustomActionParam` to `json.Number`. by [@dongwlin](https://github.com/dongwlin)
- Return errors instead of `(nil, nil)` when recognition, action, or screen stabilization wait details are unavailable. by [@dongwlin](https://github.com/dongwlin)
- Return `ErrTaskerRunning` when rebinding a Tasker with pending or running tasks. by [@dongwlin](https://github.com/dongwlin)
- Change `Release` to return `ErrLibraryInUse` while objects remain alive or Agent Server has not shut down; unloading remains disabled after detach. by [@dongwlin](https://github.com/dongwlin)

### Fixes

- Fix concurrency issues when multiple goroutines wait for or query the same Job / TaskJob. by [@dongwlin](https://github.com/dongwlin)
- Fix destruction releasing objects while native work was still active after stopping invalidated old Job IDs. by [@dongwlin](https://github.com/dongwlin)
- Fix interleaved sink and Resource runner registrations by serializing registration operations. by [@dongwlin](https://github.com/dongwlin)
- Fix Go callback records left behind after native registration failures. by [@dongwlin](https://github.com/dongwlin)
- Fix premature cleanup callback release during custom controller destruction, retaining KeyUp / TouchUp callbacks until native destruction finishes. by [@dongwlin](https://github.com/dongwlin)
- Fix incomplete shared library cleanup after initialization failures and allow retries for failed unloads. by [@dongwlin](https://github.com/dongwlin)
- Fix initialization with an empty library directory unexpectedly changing the Windows DLL search configuration. by [@dongwlin](https://github.com/dongwlin)
- Fix missing Entry and Status for tasks without nodes. by [@dongwlin](https://github.com/dongwlin)
- Fix Shell output truncation at embedded NUL bytes. by [@dongwlin](https://github.com/dongwlin)
- Fix custom recognition detail truncation at embedded NUL bytes when writing to native buffers. by [@dongwlin](https://github.com/dongwlin)
- Return errors to callers when creating or writing image and rectangle buffers fails. by [@dongwlin](https://github.com/dongwlin)
- Fix loss of flat parameters when Action / Recognition omits `param`. by [@dongwlin](https://github.com/dongwlin)
- Fix missing nested `recognition` objects when encoding And / Or inline recognition. by [@dongwlin](https://github.com/dongwlin)
- Fix partial receiver updates when Swipe action result parsing fails. by [@dongwlin](https://github.com/dongwlin)
- Report parameter encoding errors and skip native execution instead of silently substituting `{}`. by [@dongwlin](https://github.com/dongwlin)
- Return a non-nil Job in a terminal failure state when submission fails, retaining the submission error for later queries. by [@dongwlin](https://github.com/dongwlin)
- Fix duplicate handle cleanup during repeated or concurrent destruction of native objects. by [@dongwlin](https://github.com/dongwlin)
- Serialize Tasker binding and submission to prevent task submission and rebinding from interleaving. by [@dongwlin](https://github.com/dongwlin)
- Retain handle references to AgentClient's bound Resource and registered sink objects to prevent destruction while in use. by [@dongwlin](https://github.com/dongwlin)
- Serialize `Init` / `Release` and synchronize `IsInited` queries. by [@dongwlin](https://github.com/dongwlin)
- Fix `WithLibDir(".")` falling back to the system search path on Unix. by [@dongwlin](https://github.com/dongwlin)
- Fix loading checks for missing explicit library paths on macOS and restrict symbol lookup to the target library. by [@dongwlin](https://github.com/dongwlin)
- Fix `Context.GetNodeJSON` and `Resource.OverrideNext` calling native APIs from the wrong category. by [@dongwlin](https://github.com/dongwlin)
- Fix older Go wrappers potentially crashing after repeated Context / Tasker getter calls. by [@dongwlin](https://github.com/dongwlin)
- Retain existing Go registration records when custom runner replacement, unregistration, or clearing fails. by [@dongwlin](https://github.com/dongwlin)
- Release Go callback records when removing or clearing Controller sinks. by [@dongwlin](https://github.com/dongwlin)
- Reject nil custom runners; make Resource unregistration of nonexistent names a successful no-op, while preserving externally registered names and returning an error. by [@dongwlin](https://github.com/dongwlin)
- Fix nil pointer access when custom recognition returns a nil result. by [@dongwlin](https://github.com/dongwlin)
- Skip recognition detail queries when a custom action's `reco_id` is 0. by [@zmdyy0318](https://github.com/zmdyy0318) ([#44](https://github.com/MaaXYZ/maa-framework-go/pull/44))
- Retain Box and Detail from non-nil custom recognition results even when recognition does not match. by [@dongwlin](https://github.com/dongwlin)
- Accept JSON strings and objects in custom recognition detail, and return an empty action result when action detail is null. by [@dongwlin](https://github.com/dongwlin)
- Retain node details when recognition or action sub-details are missing, and skip sub-details with ID 0. by [@dongwlin](https://github.com/dongwlin)
- Handle nonzero origins and extra row stride correctly when writing sub-images. by [@dongwlin](https://github.com/dongwlin)
- Return errors for empty image inputs. by [@dongwlin](https://github.com/dongwlin)
- Return a true nil image when reading empty image buffers. by [@kqcoxn](https://github.com/kqcoxn) ([#52](https://github.com/MaaXYZ/maa-framework-go/pull/52))
- Copy relevant Attach, MultiSwipe, and ColorMatch configuration data to reduce the effect of later caller modifications on constructed configurations. by [@dongwlin](https://github.com/dongwlin)
- Accept `key_code` and OCR `text` during parameter decoding, and fix stale values when reusing parameter objects. by [@dongwlin](https://github.com/dongwlin)
- Round positive AgentClient communication timeouts below 1ms up to 1ms. by [@dongwlin](https://github.com/dongwlin)
- Align emitted Win32 screenshot names with `DXGI_DesktopDup` / `DXGI_DesktopDup_Window`, while retaining decoding compatibility with the old names. by [@dongwlin](https://github.com/dongwlin)
